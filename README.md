

# ChatWave

A real-time language exchange chat application that connects learners with native speakers around the world — with a built-in AI language assistant for practice anytime.

**Live demo:** [chat-wave-red.vercel.app](https://chat-wave-red.vercel.app)

## Features

- **Authentication** — secure signup/login with JWT, httpOnly cookies
- **Real-time chat** — 1-on-1 messaging with typing indicators and read receipts, powered by Stream Chat
- **Video calls** — one-tap video calling within any conversation
- **Friend system** — send, accept, and manage friend requests with live unread badges
- **Language exchange matching** — discover learners by native/target language, with search and filtering
- **AI Language Assistant** — a dedicated in-app AI chat partner (Google Gemini) for practicing a language anytime, with full conversation memory and a live typing indicator
- **Online presence** — real-time online/offline status on every friend
- **Notifications** — friend request and connection activity feed
- **User profiles** — editable bio, avatar, native/learning languages, and location
- **Dark mode** — full theme switching across the app
- **Responsive design** — polished experience from mobile through desktop

## Tech Stack

**Frontend**
- React + Vite
- Tailwind CSS
- TanStack Query (React Query)
- Stream Chat React SDK
- Stream Video React SDK
- React Router
- Lucide Icons

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- Stream Chat & Video server SDK
- Google Generative AI (Gemini) for the AI assistant

**Infrastructure**
- Frontend deployed on Vercel
- Backend deployed on Render
- MongoDB Atlas
- GitHub Actions for CI (lint on push/PR to `main`)

## Architecture

```
ChatWave/
├── frontend/          # React + Vite client
│   └── src/
│       ├── components/
│       ├── pages/
│       ├── hooks/
│       └── lib/
└── backend/           # Express API
    └── src/
        ├── controllers/
        ├── models/
        ├── routes/
        ├── middleware/
        ├── lib/
        └── scripts/
```

Real-time messaging and video are handled by [Stream](https://getstream.io/), so the backend focuses on auth, friend/user logic, and brokering AI responses into chat channels rather than managing sockets directly.

## Getting Started

### Prerequisites
- Node.js 18+
- A MongoDB Atlas cluster
- A [Stream](https://getstream.io/) account (Chat + Video)
- A [Google AI Studio](https://aistudio.google.com/) API key (for the AI assistant)

### Setup

```bash
git clone https://github.com/Mustee-coder/ChatWave.git
cd ChatWave
```

**Backend**
```bash
cd backend
npm install
```

Create `backend/.env`:
```
PORT=5001
MONGO_URI=your_mongodb_uri
JWT_SECRET_KEY=your_jwt_secret
STEAM_API_KEY=your_stream_api_key
STEAM_API_SECRET=your_stream_api_secret
GEMINI_API_KEY=your_gemini_api_key
AI_USER_ID=          # generated by the seed script below
NODE_ENV=development
```

Seed the AI assistant user (one-time):
```bash
node src/scripts/seedAIUser.js
```
Copy the printed `AI_USER_ID` into `backend/.env`.

Run the backend:
```bash
npm run dev
```

**Frontend**
```bash
cd frontend
npm install
```

Create `frontend/.env`:
```
VITE_STREAM_API_KEY=your_stream_api_key
VITE_AI_USER_ID=      # same AI_USER_ID as backend
```

Run the frontend:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`
